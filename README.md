# Teploty °C / °F

Python aplikácia (Tkinter + matplotlib): pole 50 náhodných teplôt, zoradenie, min/max/priemer, výpočet °C -> °F a graf.

## Spustenie
```
pip install -r requirements.txt
python main.py
```

## Vytvorenie .exe
```
pyinstaller --onefile --windowed main.py
```
Súbor sa objaví v priečinku dist/.
